Grammar Focus: so / such (Page 37)

💡 ทริคการใช้ so และ such (มากเสียจน...)

  • so + adjective (ตามด้วยคำคุณศัพท์อย่างเดียว ไม่มีคำนามต่อท้าย)
    Ex: This movie is so funny.
  • such + (a / an) + adjective + noun (ตามด้วยคำคุณศัพท์ + คำนาม)
    Ex: This is such a funny movie. / They are such nice people.
